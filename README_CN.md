# The Tamworth Chase

*一款手绘田园风、开坦克追牛、还要守住出口的回合制追逐游戏。*

农夫 John 像坦克一样驾驶：前进、左转、右转或等待。牛有自己的计划：它们会朝金色出口走，
有些牛看到农夫还会优先逃跑。玩家必须在任何一头牛逃出出口之前，抓住全部牛。

游戏完全离线：没有账号、没有服务器、没有遥测，运行时不发起任何网络请求。

## 改名说明

本项目原名为 **The Tamworth Two**，从本版本起统一更名为 **The Tamworth Chase**，
中文副标题为《塔姆沃斯追逐》。存档位置为 `~/.the_tamworth_chase/save.json`；
旧存档会在首次启动时自动迁移，并且不会被删除。

## 功能特性

- **纯驾驶。** 农夫只能前进或原地转向；没有布置阶段，也不能自己放置障碍。
- **出口压力。** 每关都有金色出口格；任何一头牛到达出口，立即失败。
- **两种牛行为。** `seek_exit` 奔向出口，看不到出口时沿墙巡逻；
  `seek_exit_and_flee` 看到农夫时优先拉开距离，否则奔向出口。
- **全部抓住才算赢。** 多牛关必须抓住所有牛；任意一头到出口就输。
- **多级撤销。** 可以撤销任意回合，恢复农夫位置/朝向、牛的位置/朝向、
  被抓住状态和回合数。
- **可配置预测。** 每关决定显示牛未来多少步（0–20，默认 5）。预测基于
  “农夫保持当前位置与朝向不变”，界面用中文标注。
- **出口警示。** 出口画成木门；牛进入 3 格范围时出口高亮并出现中文提示。
- **警觉图标。** 正在逃跑的牛头顶会出现感叹号；可在顶栏或设置里关闭。
- **独立教程。** 基础 6 课、进阶 3 课、编辑器 3 课，独立进度、跳过、重玩、重置，
  并有强制小练习。
- **挑战与每日。** 5 个挑战关；每日牧场由本地日期种子生成，并在设备上做有限搜索。
- **关卡编辑器。** 画地形、摆农夫和最多三头牛、设置出口/行为/视野/回合，试玩，
  导出/导入 JSON。
- **程序化绘本美术。** 草地、栅栏、树篱、水塘、牛、农夫、出口门和警觉气泡都由代码绘制；
  没有用 emoji 充当游戏对象。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## 运行

```bash
.venv/bin/python main.py
```

## 操作方式

| 输入 | 行为 |
|---|---|
| `W` / `↑` | 朝当前朝向前进一格 |
| `A` / `←` | 原地左转 90° |
| `D` / `→` | 原地右转 90° |
| 空格 | 原地等待 |
| `U` | 撤销一个回合 |
| `R` | 重开本关 |
| `P` | 开关路径预测 |
| `Esc` | 返回上一级 |

顶栏还有「撤销」「重开」「预测」「警觉」按钮。没有暂停、单步、速度档位；
节奏由玩家操作决定。

## 规则

### 状态机

```
游玩中 ⇄ 撤销 / 重开 → 胜利 / 失败
```

没有布置阶段，关卡加载后直接进入游玩中。结算弹窗提供「撤销到上一回合」
「重开本关」「返回」。

### 一个回合

1. 玩家执行且只执行一个动作：前进、左转、右转或等待。
2. 前进时，若目标格是墙、边界或固定障碍，位置与朝向不变，但本回合仍然消耗，
   并提示「前方受阻，本回合已消耗」。
3. 农夫移入牛所在格时，该牛被抓住。
4. 若所有牛都被抓住，立即胜利。
5. 所有牛按关卡顺序依次移动。
6. 每头牛移动后：若到达出口，立即失败；若与农夫同格，该牛被抓住。
7. 所有牛移动后，若全部被抓住则胜利；否则回合数加一。达到回合上限仍未胜利则失败。

## 牛的行为

### `seek_exit`（默认）

- 若出口在牛的直线视野内（同行或同列，中间没有墙/固定障碍/边界，
  距离不超过 `exit_sight_range`），牛会转向出口；已经朝向出口时直接前进。
- 多个出口都可见时选曼哈顿距离最近的；距离相同按坐标 `(行, 列)` 排序。
- 看不到出口时沿墙巡逻：前方可走则前进，否则顺时针转 90° 原地不动。

### `seek_exit_and_flee`

- 农夫在视野内时，逃跑优先于出口。
- 视野判定：同行或同列、中间无地形遮挡、距离不超过 `sight_range`
  （-1 表示无限）；`cows_block_sight` 为真时其他牛也会挡住视线。
- 前方可走且前进后与农夫的曼哈顿距离严格变大，则前进；否则比较左转/右转后
  前方一格与农夫的距离，选择更远的一侧；距离相同由 `flee_tiebreak` 决定。
- 农夫不在视野内时，恢复普通的奔出口行为。

牛只会通过“逃跑”规则对农夫作出反应。牛移入农夫所在格会被抓住；被抓住的牛
从棋盘上移除，不再移动、阻挡视线或触发出口。

## 胜负条件

- **胜利：** 抓住全部牛。单牛关即抓住该牛；多牛关必须全抓。
- **失败：** 任意一头牛到达任意出口格。
- **失败：** 回合数达到 `max_turns` 且没有胜利。
- 最后一回合的获胜操作仍然有效。
- 失败弹窗区分「牛从出口逃走了」和「回合数用完了」。

## 预测、警觉与循环

预测显示牛接下来最多 `prediction_steps` 个姿态，假设农夫保持当前位置与朝向不变。
用半透明脚印和虚线绘制，中文标注该假设。预测中若牛会到达出口，路径终点用红色标出。
`0` 表示该关关闭预测。

顶栏「警觉」按钮开关逃跑牛头顶的感叹号图标；设置页也可调整。

若完整局面（农夫位置/朝向、所有牛位置/朝向、被抓住状态）重复，会出现中文
「局面进入循环」提示。它不会判负，只会提醒玩家换一条路线。

## 主线与评价

- 10 张 10×10 主线关卡，逐关解锁，第一关始终可用。
- 每关保存最好回合数与 S/A/B/C 评价；阈值来自 `s_threshold`、`a_threshold`、
  `b_threshold`。
- 第 6、7、8、10 关使用会逃跑的牛；第 8、10 关是双牛关；第 9 关关闭预测。
- 出口属于固定地形，在关卡预览中可见。

## 挑战、每日与成就

- **挑战：** 5 个独立关卡，记录本地最好回合数。
- **每日：** 用本地日期作为种子生成牧场，生成时在设备上做有限 BFS 验证；
  所有候选都失败时才回退到主线第一关。
- **成就：** `one_step`（一步抓牛）、`close_call`（最后一回合）、
  `flawless`（没有前进撞墙）、`loop_free`（没有循环提示）、
  `all_levels`（通关十个主线关卡）。

## 关卡编辑器

- 绘制草地、栅栏、树篱、树木、水塘。
- 放置农夫，移动/添加/删除最多三头牛，并可切换当前牛。
- 用「出口格」工具点击可走格添加/移除出口；至少需要一格出口。
- 用「固定障碍」工具添加/移除固定干草垛。
- 调整回合上限、预测步数、视野距离、出口视野。
- 切换当前牛的行为、出口/逃跑平局方向、牛挡视线、牛互相阻挡。
- 试玩使用正式模拟；导出到 `custom_levels/`，导入读取文件中的第一张关卡。
- 关卡名固定为「我的牧场」，暂不支持文字输入。

## 关卡数据格式

```json
{
  "id": "level_01",
  "name": "晨露草坪",
  "grid": ["##########", "#........#", "..."],
  "fj_start_direction": "north",
  "cow_facings": ["east"],
  "cow_behavior": "seek_exit",
  "exit_cells": [[1, 1]],
  "max_turns": 16,
  "prediction_steps": 5,
  "exit_sight_range": -1,
  "sight_range": 6,
  "exit_tiebreak": "right",
  "flee_tiebreak": "right",
  "cows_block_sight": false,
  "cows_block_each_other": false,
  "obstacles": [],
  "hint": "把农夫开到牛和出口之间；撞墙前进会浪费回合。",
  "goal": "抓住全部牛"
}
```

| 字段 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `id` | string | 必填 | 唯一关卡 id |
| `name` | string | id | 中文显示名 |
| `grid` | string[] | 必填 | 地形行；`F` 农夫，`C` 牛 |
| `fj_start_direction` | string | `north` | 农夫初始朝向（也接受 up/right/down/left） |
| `cow_facings` | string[] | `east` | 每头牛的初始朝向 |
| `cow_behavior` | string 或 string[] | `seek_exit` | 统一行为或逐牛行为 |
| `exit_cells` | `[row,col][]` | 必填 | 至少一格可走出口 |
| `max_turns` | int | 30 | 回合上限 |
| `prediction_steps` | int | 5 | 预测步数；0 关闭 |
| `exit_sight_range` | int | -1 | 出口视野距离；-1 无限 |
| `sight_range` | int | -1 | 农夫视野距离；-1 无限 |
| `exit_tiebreak` / `flee_tiebreak` | `right` / `left` | `right` | 平局方向 |
| `cows_block_sight` | bool | false | 牛是否挡农夫视线 |
| `cows_block_each_other` | bool | false | 牛是否互相阻挡移动 |
| `walls` | `[row,col][]` | `[]` | 可选的额外栅栏坐标（会折进网格） |
| `obstacles` | `[row,col][]` | `[]` | 可选的固定干草垛 |
| `s/a/b_threshold` | int | 自动推导 | 按回合数的评价阈值 |
| `hint` / `description` / `goal` / `practice` | string | `""` | 中文界面文本 |
| `tips` | `{trigger,text}[]` | `[]` | 教程提示 |

网格字符：`.` 草地、`,` 花、`#` 栅栏、`T` 树、`~` 水塘、`H` 树篱、
`F` 农夫、`C` 牛。旧地图里的 `D/G/S` 仍按普通牛读取；牛不能出生在出口上。

**向后兼容：** 旧的 `step_limit`、`obstacle_limit`、`initial_obstacles`、
`win_condition`、`pen_cells`、牛性格和道具字段会被忽略；`step_limit` 作为
`max_turns` 的回退。旧关卡没有出口时，会选一个确定性的远端可走格作为默认出口，
并标记为 legacy；旧自定义关卡仍能加载。

## 设计说明与假设

- **全部抓住才胜，任一牛到出口即负**：严格按规格实现，单牛和多牛一致。
- **回合上限**：达到 `max_turns` 仍未胜利即失败；同一回合的胜利判定先执行，
  所以最后一回合仍可获胜。
- **出口直线视野**：严格按“同行或同列”实现；对角出口不属于直线视野，牛会走巡逻。
  规格里“对角出口”的括号说明与直线定义冲突，因此按直线定义执行。
- **被抓住的牛离开棋盘**：快照保留其位置用于撤销，但移动、视线、出口和渲染都跳过。
- **`cow_behavior`**：接受单个字符串（全牛统一）或数组（逐牛），支持混合行为。
- **固定地形**：网格 + 可选 `walls`/`obstacles`。`walls` 折进网格；`obstacles`
  是固定干草垛。
- **预测**只模拟牛，农夫固定；没有实现“农夫每个候选动作下牛的反应”这一可选进阶视图。
- **练习门禁**只用于教程，不影响主线。

## 已知限制

- 图形界面通过无窗口截图与注入事件验证，未在物理显示器上做人工手感测试。
- 音效在 dummy 设备下运行，未做听感验收。
- 编辑器关卡名固定、画布固定 10×10。
- 每日生成器所有候选都失败时回退到主线第一关。
- 每次尝试最多保留 256 个撤销快照。
- 解析器本身不限制 10×10，但编辑器画布限制为 10×10。
