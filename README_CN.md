# The Tamworth Two

*一款用纯 Python 制作的手绘田园风网格追逐解谜游戏。*

农夫 John 和他的牛走路方式一模一样：前方能走就前进一格，否则顺时针转 90° 原地不动。
两位主角永远同步移动。你要在追逐开始前放下几捆干草垛，让两条路线互相咬合，
在步数用完之前让农夫抓到牛——同时别让时间绕成一个圈。

游戏完全离线：没有账号、没有服务器、没有遥测，运行时不发起任何网络请求。

## 功能特性

- 10 张手工设计的 10×10 主线牧场，难度循序上升。
- 严格同步的双主角追逐模拟，带完整的时间闭环检测。
- 有限次数的干草垛放置、撤销，以及前三步轨迹预测。
- 播放控制：开始、暂停、单步、0.5× / 1× / 2× 速度、重开。
- 基于步数的 S/A/B/C 评价，最好成绩保存在本地。
- 主线关卡逐关解锁，另有独立设置页面。
- 界面、关卡名、提示与弹窗全部为简体中文。
- 全部美术由代码程序化绘制：草地、木栅栏、树篱、树木、水塘、农夫与牛，
  不依赖任何位图素材。

> **里程碑状态。** 当前版本为可玩的 MVP：完整的关卡、模拟、界面、评价与存档系统。
> 独立新手教程章节、第二头牛与性格、道具、挑战模式与关卡编辑器属于下一个里程碑；
> 其数据文件与接口已在项目结构中预留，后续接入不需要改动核心规则。

## 环境要求

- Python 3.10 或更高版本（开发与验证环境为 CPython 3.14）。
- 可用的桌面窗口环境（macOS、Windows 或 Linux）。
- `pygame-ce` 负责窗口、绘制与音频；`pytest` 仅用于测试。

## 虚拟环境与安装

项目使用仓库根目录下的 `.venv/` 虚拟环境。

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Windows（PowerShell）：

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如果不激活环境，也可以直接使用显式解释器路径：

```bash
.venv/bin/python main.py
.venv/bin/python -m pytest
```

依赖在 `requirements.txt` 中限定版本范围：

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| pygame-ce | >=2.5,<2.6 | 窗口、渲染、输入与音频混音 |
| pytest | >=8,<9 | 仅用于单元测试 |


## 操作方式

| 操作 | 效果 |
| --- | --- |
| 鼠标左键 | 在草地上放置干草垛（仅限追逐开始前） |
| 左键点击干草垛 | 把它收回来 |
| 鼠标右键 | 收回光标下的干草垛 |
| `空格` | 开始追逐，或暂停 / 继续 |
| `S` 或 `→` | 单步前进一回合 |
| `R` | 重开本关 |
| `1` / `2` / `3` | 播放速度切换为 0.5× / 1× / 2× |
| `P` | 开 / 关前三步预测 |
| `Esc` | 返回 |

所有操作也都能在右侧面板的按钮上完成。

## 游戏规则

1. 棋盘是 10×10 的牧场，四周被栅栏包围。
2. 农夫 John 与每一头牛都占据一个格子，并朝向东南西北之一。
3. 每一回合双方**同步**推进：先根据当前状态计算农夫和所有牛的下一状态，
   再统一提交，绝不允许先动一方。
4. 若正前方格子可通行，则前进一格并保持朝向；否则原地顺时针旋转 90°，本回合不移动。
5. 栅栏、树篱、树木、水塘、边界和干草垛都会阻挡移动。
   角色之间互不阻挡——他们可以迎面交换格子而不会相遇。
6. 若一回合结束后农夫与某头牛处在同一格，即抓住牛，立即获胜。
7. 若完整状态重复出现——农夫位置与朝向、每头牛的位置与朝向、障碍布局——
   判定进入时间闭环，本局失败。
8. 若步数预算耗尽仍未抓住牛，本局失败。

模拟逻辑位于 `game/core.py`，完全不依赖 pygame，因此上述每条规则都有单元测试覆盖。

## 进度、评价与解锁

- 主线关卡按顺序解锁：通关当前关才会开启下一关。
- 评价只看使用步数：
  - **S** —— 不超过该关的 S 阈值
  - **A** —— 不超过 A 阈值
  - **B** —— 不超过 B 阈值
  - **C** —— 完成关卡但超过 B 阈值
- 每关保存最好步数与最好评价；评价只升不降。
- 教程进度保存在存档的**独立分区**，绝不影响主线解锁；主线进度也不会把教程课标记为完成。

## 字体与许可

界面使用 **CEF Fonts CJK（快去写作业CJK）**。这是一款完全用鼠标绘制字形的仿手写字体，
为界面带来绘本般的亲近感。

- 字体：CEF Fonts CJK，Regular
- 作者：Partyb0ssishere
- 来源仓库：<https://github.com/Partyb0ssishere/cef-fonts-cjk>
- 许可：SIL Open Font License, Version 1.1
- 本地文件：`assets/fonts/CEFFontsCJK-Regular.ttf`
- 许可全文：`assets/fonts/OFL.txt`

字体在开发阶段一次性下载并随仓库分发，游戏运行时**不会**联网加载。
OFL 允许免费使用、嵌入与再分发，前提是保留许可文本，且不得单独售卖字体文件本身。

`game/theme.py` 处理了两个实际问题：

1. **回退链**：内置字体缺失时，依次回退到系统圆体 / 黑体，再到系统默认中文字体，
   确保任何机器上中文都可读。
2. **数字可读性**：CEF Fonts CJK 的 `1` 是一笔斜杠，容易与 `/` 混淆。
   因此数字使用圆体系统字体渲染（SF Rounded → Avenir Next → Helvetica Neue →
   DejaVu Sans → Arial → 内置字体），中文与拉丁字母保留手写体风格。
   正文最小字号为 18 px。

字体文件以未修改形式按 SIL OFL 1.1 再分发，完整许可见 `assets/fonts/OFL.txt`。

## 美术、音效与离线资源

- **美术**：所有画面元素都由 `game/art.py` 与 `game/render.py` 在运行时程序化绘制：
  带柔和纹理的草地、与相邻格自动连接的木栅栏、树篱、树林、水塘、农夫、
  四种朝向的牛、干草垛与道具。游戏不包含任何位图精灵表。
- **音效**：所有音效都在启动时由 `game/audio.py` 用简单波形合成，没有音频文件需要下载。
  设置页可以关闭音效。
- **离线**：游戏不发起任何网络请求。仓库中唯一的二进制资源是内置字体。

## 存档位置

进度以 JSON 形式保存在仓库之外：

- 默认：`~/.the_tamworth_two/save.json`

`achievements`、`challenges`、`daily`。写入采用原子替换；存档损坏时会回退为全新存档而不是崩溃。

## 设计说明与假设

- **同步是构造出来的**：每回合先计算所有角色的下一状态，之后再统一提交；
  这是角色交换格子时规则仍然正确的唯一做法。
- **时间闭环的状态键**：包含农夫格与朝向、每头牛的格与朝向、障碍布局。
  一旦新回合产生已经出现过的键，本局以时间闭环结束。
- **步数预算**：上限为 n 步的关卡恰好允许 n 次移动；到点仍未抓牛则失败。
- **干草垛**是主线中唯一的开局布置物；不能放在栅栏、树、水塘、树篱、牧场之外、
  角色身上或已有干草垛上，追逐开始后也不能再放。
- **评价**只由步数推导，结果确定、可测试，不涉及隐藏计时。
- 渲染以 60 FPS 运行，可在设置中开启低配模式（关闭粒子与复杂动效）。
