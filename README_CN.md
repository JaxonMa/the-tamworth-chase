# The Tamworth Chase

*一款用纯 Python 制作的手绘田园风回合制追逐解谜游戏。*

农夫 John 想抓住牧场上的牛。每个回合，玩家先让农夫走一格或原地等待，然后牛才会走一步。
牛一直向前走；前方是围栏、树木、边界或干草垛时，它就顺时针转 90° 并留在原地。
观察路线、用干草改变方向、用撤销修正判断，在回合用完之前抓住牛。

游戏完全离线：没有账号、没有服务器、没有遥测，运行时不发起任何网络请求。

## 改名说明

本项目原名为 **The Tamworth Two**，从本版本起统一更名为 **The Tamworth Chase**，
中文副标题为《塔姆沃斯追逐》。存档位置改为 `~/.the_tamworth_chase/save.json`；
旧存档会在首次启动时自动迁移，并且不会被删除。

## 功能特性

- **直接操控。** 用方向键或 WASD 移动农夫，按空格等待；玩家操作之后，牛才走一步。
  每个回合都是一次小决策，而不是开局布置后看自动演示。
- **10 张主线关卡**，全部是 10×10 牧场，其中包含双牛关和无预测关。逐关解锁，
  用时越少评价越高（S/A/B/C）。
- **多级撤销。** 可以撤销任意一个回合，甚至一路退回布置阶段；布置阶段放下的干草
  也能撤销，开始追逐后同样可以退回布置。
- **可配置路径预测。** 每关自行决定显示牛未来多少步（0–20，默认 5）。预测用半透明
  脚印和虚线绘制，随时可以按 `P` 开关。
- **循环提示，不判负。** 牛的位置与朝向组合重复时会出现中文提示，游戏继续；
  玩家可以继续行动或换一条路线打破循环。
- **两种胜利条件。** 抓住任意一头牛；或在围栏关里，让所有牛同时站在围栏格中。
- **独立教程章节。** 基础 5 课、进阶 3 课、编辑器 3 课。教程有独立入口、独立进度、
  独立的跳过/重玩/重置；教程完成不会解锁主线关卡。
- **挑战与每日模式。** 5 个精选挑战关；每日牧场由本地日期种子生成，并在设备上
  做有限搜索确认可解。
- **关卡编辑器。** 画地形、摆农夫与最多三头牛，设置回合上限、障碍数量、预测步数、
  胜利条件，画围栏格，试玩，导出/导入普通 JSON。
- **成就。** 一步抓牛、零障碍通关、围栏里的牛、一气呵成、牧场主，全部本地保存。
- **程序化绘本美术。** 草地、栅栏、树篱、水塘、树木、农夫、牛、干草垛和围栏格
  都由代码绘制；没有位图精灵表，也没有用 emoji 充当游戏对象。
- **中文字体本地化。** CEF Fonts CJK 随游戏打包，运行时从本地加载。

## 环境要求

- Python 3.10 或更新版本（开发与验证使用 Python 3.14.7）
- `pygame-ce` 2.5.x
- `pytest`（仅测试需要）
- macOS、Linux 或 Windows 的桌面环境（运行图形界面）

## 虚拟环境与安装

项目使用独立的 `.venv`，依赖不会装进全局 Python。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Windows 下的解释器路径是 `.venv\Scripts\python.exe`。

## 运行游戏

```bash
.venv/bin/python main.py
```

窗口大小为 1280×840。所有玩家可见文本使用简体中文；代码标识符、注释、docstring
使用英语。

## 操作方式

| 输入 | 行为 |
|---|---|
| 方向键 / `W` `A` `S` `D` | 让农夫走一格 |
| 空格 | 原地等待一回合（布置阶段则开始追逐） |
| 鼠标左键 | 布置阶段放置 / 收回干草垛 |
| 鼠标右键 | 布置阶段收回干草垛 |
| `U` | 撤销一次操作（布置或回合） |
| `R` | 回到本关布置阶段 |
| `P` | 开关路径预测 |
| `Esc` | 返回上一级界面 |

顶部还有可点击的「撤销」「重开」「预测」按钮。游戏没有暂停、单步、速度档位：
节奏由玩家的操作决定。

## 游戏规则

### 状态机

```
布置阶段 → 游玩中 ⇄ 撤销 / 重开 → 胜利 / 失败
```

- **布置阶段：** 在允许范围内放置干草垛。干草不能放在农夫、牛、墙或另一垛干草上。
  按空格或点击开始按钮进入游玩。
- **游玩中：** 每个回合先执行玩家操作，再让所有牛各走一步。
- **结束：** 胜利或失败后弹出结算。失败可以撤销到上一回合或重开；胜利可以进入
  下一关/下一课，也可以重玩。

### 回合流程

1. 玩家让农夫向北/东/南/西移动一格，或者原地等待。
2. 如果目标格是墙、边界或干草垛，这次操作无效：不消耗回合，并用中文提示原因。
3. 农夫移动，朝向改为移动方向；等待时保持原朝向。
4. 如果农夫与任意牛同格，立即胜利。
5. 所有牛按固定顺序各移动一次：前方能走则前进一格，否则顺时针转 90° 原地不动。
6. 如果牛移动后与农夫同格，立即胜利。
7. 围栏关中，如果所有牛都在围栏格上，立即胜利。
8. 回合数加一；达到关卡回合上限仍未胜利则失败。

农夫与牛之间不会互相阻挡，只有地形、边界和干草垛会阻挡。农夫可以走进牛的格子
完成抓牛。

### 牛与移动顺序

- 牛是完全确定性的，不会追人、逃跑或对农夫做出反应。
- 多牛关卡按列表顺序移动；前面的牛先提交，后面的牛再走。
- `cows_block_each_other`（默认 `false`）为真时，牛会把另一头牛的当前格视为障碍；
  排队的牛会把后一头牛挤成原地转身。这个规则有单元测试，并在一张主线/挑战关中
  实际使用。

### 胜利与失败

- **抓住：** 农夫与任意牛同格。农夫移动后检查一次，牛移动后再检查一次。抓住始终
  算胜利，围栏关也一样。
- **围栏：** 所有牛同时位于围栏格。围栏关通常把牛放在农夫进不去的封闭区域里，
  所以围栏才是实际解法。
- **回合上限：** 回合数达到 `max_turns` 仍未获胜则失败。最后一回合仍然可以获胜。
- **循环提示：** 牛的位置与朝向重复时弹出中文提示和轻音效，但绝不判负。
- **撤销：** 恢复农夫、所有牛、干草垛、回合数和循环历史。失败弹窗提供
  「撤销到上一回合」和「重开本关」。

### 路径预测

预测只模拟牛，假设农夫在等待；最多显示 `prediction_steps` 个未来牛姿态，用虚线
和脚印表示。`0` 表示该关关闭预测，此时按 `P` 会用中文提示本关没有预测。预测不会
修改正在进行的游戏状态。

## 主线、评价与解锁

- 10 张主线关卡，`level_01` … `level_10`，全部 10×10。
- 通关上一关解锁下一关；第一关始终可用。
- 评价按回合数计算：每关定义 `s_threshold`、`a_threshold`、`b_threshold`，
  回合越少越好。
- 每关保存最好回合数与评价。教程进度保存在存档的另一个分区，永不影响主线解锁。
- 第 8 关和第 10 关是双牛关；第 9 关 `prediction_steps` 为 0。

## 新手教程章节

教程是三章独立的「小书」：

| 章节 | 文件 | 课数 | 内容 |
|---|---|---|---|
| 基础教程 | `tutorials/basics.json` | 5 | 移动、墙角、等待、撤销、预测 |
| 进阶教程 | `tutorials/advanced.json` | 3 | 多头牛、围栏胜利、循环提示 |
| 编辑器教程 | `tutorials/editor.json` | 3 | 画地形、新规则字段、导出/导入 |

- 每章有独立进度、独立入口、课程列表、跳过按钮和重置按钮；课程按顺序解锁，
  已完成的课可以重玩。
- 可以跳过单课、跳过整章，也可以在设置里重置全部教程进度。
- 部分课程有强制小练习：必须先放干草、必须先撤销、必须先打开预测，或必须先等待
  至少一回合。面板的提示框下方会显示本课练习。
- 教程关卡不参与 S/A/B/C 评价。
- 循环课在循环提示出现时完成，不需要故意输一局。

## 挑战、每日与成就

- **挑战：** 5 个独立关卡（`levels/challenges.json`），只记录本地最好回合数，
  不消耗主线进度。
- **每日：** 用本地日期作为固定种子生成牧场；生成时在设备上做有限搜索确认可解，
  只有所有候选都失败时才回退到主线第一关。保留最近七天的本地记录。
- **成就：** `one_step`（一步抓牛）、`no_obstacles`（零障碍通关）、
  `fenced_cow`（围栏里的牛）、`loop_free`（一气呵成）、`all_levels`（牧场主）。
  每个成就只解锁一次并写入存档。

## 关卡编辑器

- 绘制草地、栅栏、树篱、树木、水塘。
- 摆农夫，移动第一头牛，最多添加三头牛。
- 设置 `initial_obstacles`（0–9）、`max_turns`（5–120）、`prediction_steps`（0–20）
  和 `cows_block_each_other`。
- 在「抓住」和「围栏」之间切换胜利条件；选择围栏格工具后点击可走的地块，
  可以添加/移除围栏格。
- 试玩使用与正式关卡完全相同的模拟；导出会写入 `custom_levels/` 下的普通 JSON，
  导入会读取文件中的第一张关卡。
- 编辑器教程覆盖画地形、新规则字段和导出/导入。关卡名目前固定为「我的牧场」，
  没有文字输入框。

## 关卡数据格式

关卡是 JSON 对象，放在 `levels/*.json` 或 `tutorials/*.json` 中：

```json
{
  "id": "level_01",
  "name": "晨露草坪",
  "grid": ["##########", "#........#", "..."],
  "farmer_facing": "east",
  "cow_facings": ["north"],
  "max_turns": 20,
  "initial_obstacles": 1,
  "prediction_steps": 5,
  "win_condition": "catch",
  "pen_cells": [],
  "cows_block_each_other": false,
  "s_threshold": 8,
  "a_threshold": 12,
  "b_threshold": 16,
  "hint": "先按方向键走一步，看看牛怎么动。",
  "description": "新的一天从一片开阔的草地开始。",
  "goal": "抓住牛",
  "practice": "用方向键移动农夫。",
  "tips": [{"trigger": "start", "text": "..."}]
}
```

| 字段 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `id` | string | 必填 | 唯一关卡 id |
| `name` | string | id | 中文显示名 |
| `grid` | string[] | 必填 | 牧场网格 |
| `farmer_facing` | string | `east` | 农夫初始朝向（仅视觉；移动不受限） |
| `cow_facings` | string[] | `east` | 每头牛的初始朝向，按牛的顺序 |
| `max_turns` | int | 30 | 回合上限 |
| `initial_obstacles` | int | 3 | 开局可放置的干草垛数量 |
| `prediction_steps` | int | 5 | 路径预测步数；0 表示关闭 |
| `win_condition` | `"catch"` / `"pen"` | `catch` | 胜利条件 |
| `pen_cells` | [row, col][] | `[]` | 围栏模式必填 |
| `cows_block_each_other` | bool | false | 牛之间是否互相阻挡 |
| `s/a/b_threshold` | int | 自动推导 | 按回合数的评价阈值 |
| `hint` / `description` / `goal` / `practice` | string | `""` | 中文界面文本 |
| `tips` | `{trigger, text}[]` | `[]` | 教程提示 |

网格字符：`.` 草地、`,` 花、`#` 栅栏、`T` 树、`~` 水塘、`H` 树篱、`F` 农夫、
`C` 牛。旧地图中用 `D`、`G`、`S` 表示的牛仍然可以读取，会当作普通牛处理；
牛的性格已经移除。

**向后兼容：** 旧文件的 `step_limit` 和 `obstacle_limit` 会分别作为 `max_turns`
和 `initial_obstacles` 的回退值读取。只属于已移除的自动同步玩法的字段
（`speed`、`pause`、道具、苹果、牛性格）会被忽略。缺失的新字段使用默认值。

## 存档位置

进度以 JSON 形式保存在仓库之外：

- 默认：`~/.the_tamworth_chase/save.json`
- 覆盖：启动前设置环境变量 `TAMWORTH_CHASE_DATA` 指向自定义目录；
  改名前的旧环境变量仍然兼容。
- 改名后的首次启动会把旧存档复制到新位置，旧文件不会被删除，并在启动时弹出
  迁移提示。旧存档损坏时会给出提示并使用全新存档，不会崩溃。

存档把以下分区严格分开：`settings`、`main`（主线）、`tutorial`（教程）、
`achievements`、`challenges`、`daily`、`custom`。写入采用原子替换；存档损坏时
回退为全新存档。存档版本 4 会把「步数」记录迁移为「回合」记录，并移除旧的
速度设置。

## 设计说明与假设

- **抓住始终算胜利。** 规则写明农夫移入牛所在格立即获胜，所以围栏关也保留这条。
  围栏关把牛放在农夫进不去的封闭区域，使围栏成为实际解法。
- **牛不会对农夫做出反应。** 它们的路线只取决于地形、干草和彼此，因此完全可预测，
  预测结果与真实移动一致。
- **预测假设农夫等待。** 它展示的是牛的未来姿态，不是玩家自己的路线。
- **循环提示只是信息。** 牛的状态是「位置 + 朝向」的元组；重复时设置提示并计数，
  但不会结束本局。
- **撤销基于快照。** 每次布置或回合都会压入完整快照（农夫、牛、干草、回合数、
  循环历史）。撤销恢复快照；内部保留重做栈，但没有绑定按键。
- **等待也是回合。** 它会消耗回合上限，并让所有牛移动。
- **没有隐藏的实时压力。** 游玩过程中没有实时时钟，唯一的限制是回合上限。

## 已知限制

- 图形界面在无窗口模式下通过渲染截图和注入事件验证，尚未在本环境的物理显示器上
  做人工手感测试。
- 音效为合成音频，代码路径在 dummy 音频设备下运行过，但没有做听感验收。
- 编辑器关卡名固定，没有文字输入。
- 每日生成器在所有候选都失败时会回退到主线第一关。
- 每次尝试的撤销快照最多保留 256 个。
- 编辑器的画布固定为 10×10。
