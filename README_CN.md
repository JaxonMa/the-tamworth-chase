# The Tamworth Chase

*一款手绘田园风、绝对方向驾驶、要守住出口的回合制追逐游戏。*

农夫 John 使用绝对方向驾驶：每回合可以转向朝上/下/左/右，或朝当前朝向
前进一格。牛始终以出口为目标：看到农夫会临时逃跑，但当逃跑方向无法拉开
距离时会立刻回落到奔向出口，不再在角落原地打转。玩家必须在任何一头牛到达
出口之前，抓住全部牛。

游戏完全离线：没有账号、服务器、遥测，运行时不发起任何网络请求。

## 改名说明

本项目原名为 **The Tamworth Two**，从本版本起统一更名为 **The Tamworth Chase**，
中文副标题为《塔姆沃斯追逐》。存档位置为 `~/.the_tamworth_chase/save.json`；
旧存档会在首次启动时复制到新位置，并且不会被删除。

## 功能特性

- **纯驾驶。** 没有布置阶段，玩家不能放置障碍；进入关卡直接游玩。
- **绝对方向。** `W`/`↑` 朝上，`S`/`↓` 朝下，`A`/`←` 朝左，`D`/`→` 朝右，
  空格朝当前朝向走一格。朝当前朝向的方向键无效，不消耗回合。
- **没有等待。** 每个有效回合都必须转向或前进。
- **出口优先的牛 AI。** 牛以出口为目标；看到农夫时会临时逃跑。如果前进和
  左右转都不能拉开距离，牛立即回落到奔向出口，不再原地打转。
- **农夫不能使用出口。** 出口只对牛可通行；农夫不能进入或停留在出口格。
  尝试前进到出口会消耗回合并提示「出口不可通行，本回合已消耗」，
  防止玩家靠站在出口上阻止牛逃脱。
- **出口压力。** 任何一头牛到达出口，立即失败。
- **全部抓住才算赢。**
- **多级撤销。** 恢复农夫位置/朝向、牛的位置/朝向、被抓住状态和回合数。
- **可配置预测。** 每关决定显示牛未来多少步（0–20，默认 5）；
  预测基于农夫保持当前位置与朝向不变。
- **渐进式教学融入主线。** 没有独立教程入口、章节选择页或教程存档段；
  前 8 关承担教学功能。
- **教学目标不通关。** `learning_objective` 只用于提示与结算展示；
  玩家以任何合理方式通关都会解锁下一关。
- **挑战与每日。** 5 个挑战关；每日牧场由本地日期种子生成，并用共享求解器验证。
- **关卡编辑器。** 画地形、摆农夫和最多三头牛、设置出口/固定障碍/视野/回合，
  试玩，导出/导入 JSON；导出前自动做可解性验证。
- **程序化绘本美术。** 草地、栅栏、树篱、水塘、牛、农夫、出口门和警觉气泡
  都由代码绘制；没有用 emoji 充当游戏对象。

## 操作方式

| 输入 | 行为 |
|---|---|
| `W` / `↑` | 转向朝上（与当前朝向相同时无效） |
| `S` / `↓` | 转向朝下（与当前朝向相同时无效） |
| `A` / `←` | 转向朝左（与当前朝向相同时无效） |
| `D` / `→` | 转向朝右（与当前朝向相同时无效） |
| 空格 | 朝当前朝向前进一格 |
| `U` | 撤销一个回合 |
| `R` | 重开本关 |
| `P` | 开关路径预测 |
| `Esc` | 返回上一级 |

按当前朝向对应的方向键会提示「已朝该方向」，不消耗回合。顶栏还有「撤销」
「重开」「预测」「警觉」按钮。教学提示可在设置页关闭。没有等待、暂停、
单步或速度档位。

## 规则

### 状态机

```
游玩中 ⇄ 撤销 / 重开 → 胜利 / 失败
```

没有布置阶段，进入关卡直接游玩。结算弹窗提供「撤销到上一回合」
「重开本关」「返回」。

### 一个回合

1. 玩家执行且只执行一个动作：朝上/下/左/右转，或前进。
2. 转向到不同方向时，位置不变、朝向改变、消耗一回合；转向到当前朝向无效，
   不消耗回合。
3. 前进时：
   - 撞墙、边界或固定障碍：位置与朝向不变，本回合消耗，提示「前方受阻，本回合已消耗」。
   - 目标格是出口：位置与朝向不变，本回合消耗，提示「出口不可通行，本回合已消耗」。
   - 目标格有牛：农夫移入，抓住该牛。
4. 农夫行动后，若全部牛被抓住，立即胜利。
5. 所有牛按固定顺序移动。每头牛移动后：到达出口立即失败；与农夫同格则被抓住。
6. 所有牛移动后，若全部被抓住则胜利；否则回合数加一。
   达到回合上限仍未胜利则失败。

最后一回合的获胜操作先判定，仍然有效。加载关卡时，农夫初始位置不能与出口重合。

## 牛的行为

所有牛使用同一套决策顺序。

### 1. 能看到农夫吗？

同时满足：

- 同一行或同一列；
- 中间没有墙、固定障碍或边界；
- 曼哈顿距离不超过 `sight_range`（-1 表示无限）；
- 若 `cows_block_sight` 为真，其他牛也会挡住视线。

### 2. 先尝试临时逃跑

- 前方可通行，且前进后与农夫的曼哈顿距离严格变大，则前进一格。
- 否则考虑左转/右转：只有“前方格可通行且距离严格变大”的一侧才算逃跑方向。
- 至少一侧可逃跑时，朝距离更远的一侧转向；平局由 `flee_tiebreak` 决定（默认 right）。
- 两侧都不能有效逃跑时，**不要原地转向**，立即进入第 3 步的出口逻辑。
  这就是“角落原地打转”问题的修复点。

### 3. 奔向出口

- 出口在直线视野内：同行或同列、中间无遮挡、距离不超过 `exit_sight_range`
  （-1 表示无限）。
- 多个出口可见时选曼哈顿距离最近的；距离相同按 `(行, 列)` 字典序。
- 牛当前正好朝向出口且前方可通行，则前进；否则转向出口方向。
  出口在正后方时由 `exit_tiebreak` 决定先向哪边转 90°，之后继续转。
- 看不到出口时沿墙巡逻：前方可走则前进；否则顺时针转 90° 原地不动。
- 如果四个相邻格全部不可通行，牛保持原地不动，而不是无限旋转。
  现有关卡避免这种设计。

### 4. 多牛与确定性

- 牛按关卡配置顺序移动，顺序固定、结果确定。
- `cows_block_each_other` 为真时，前方有其他活动牛视为不可通行，默认关闭。
- 被抓住的牛从移动、视线、出口判定和渲染中移除；快照仍保留其位置用于撤销。

## 胜负条件

- **胜利：** 抓住全部牛。单牛关即抓住该牛；多牛关必须全抓。
- **失败：** 任意一头牛到达任意出口格。
- **失败：** 回合数达到 `max_turns` 且没有胜利。
- **失败弹窗：** 区分「牛从出口逃走了」和「回合数已用完」。
- **教学目标不是通关条件。** 提示、求解器分析、结算展示可以使用教学目标；
  通关、解锁和评价只取决于正常胜负条件。

## 渐进式主线

10 个主线关构成一条教学序列：

| # | 关卡 | 教学重点 | 牛 | 回合上限 | 最短解 |
|---|---|---|---:|---:|---:|
| 01 | 朝哪走 | 绝对转向与前进 | 1 | 14 | 6 |
| 02 | 撞墙的代价 | 撞墙浪费回合 | 1 | 18 | 9 |
| 03 | 出口在哪 | 牛会奔向出口 | 1 | 12 | 4 |
| 04 | 警觉的牛 | 牛会逃跑，逃不掉会继续奔出口 | 1 | 12 | 7 |
| 05 | 出口不可通行 | 农夫不能站上出口 | 1 | 14 | 7 |
| 06 | 墙后的伏击 | 固定地形遮挡视线 | 1 | 10 | 4 |
| 07 | 出口前的拦截 | 抢在出口前拦截 | 1 | 9 | 4 |
| 08 | 预判与撤销 | 路径预测与撤销 | 1 | 14 | 6 |
| 09 | 苔藓高地 | 多牛压力 | 2 | 27 | 19 |
| 10 | 最后的牧场 | 多牛与出口双重压力 | 2 | 33 | 25 |

- 第 1–8 关为教学关；9–10 综合运用机制。
- 每关有中文 `learning_objective` 与一组 `hint_text`；教学目标显示在游玩页和
  关卡卡片上，提示在玩家停留时逐步出现。
- 教学目标未达成不会阻塞解锁，也不会要求重玩；任何合理通关都有效。
- 教学关的胜利结算不显示 S/A/B/C 评价徽章；内部阈值仅保留数据兼容。
- 没有独立教程入口、独立教程进度、跳过/重置教程 UI。

## 预测、警觉与循环

预测显示牛接下来最多 `prediction_steps` 个姿态，假设农夫保持当前位置与朝向不变。
用半透明脚印和虚线绘制，中文标注该假设。预测中若牛会到达出口，终点用红色标出。
`0` 表示该关关闭预测。

顶栏「警觉」按钮开关逃跑牛头顶的感叹号图标；设置页还有「显示教学目标与提示」开关。

若完整局面（农夫位置/朝向、所有牛位置/朝向、被抓住状态）重复，会出现中文
「局面进入循环」提示。它不会判负，玩家可继续操作打破循环。

## 挑战、每日与成就

- **挑战：** 5 个独立关卡，记录本地最好回合数。
- **每日：** 用本地日期作为种子生成牧场，通过共享求解器验证；
  所有候选都失败时才回退到主线第一关。
- **成就：** `one_step`（一步抓牛）、`close_call`（最后一回合）、
  `flawless`（没有前进撞墙）、`loop_free`（没有循环提示）、
  `all_levels`（通关十个主线关卡）。

## 编辑器与求解器

- 绘制草地、栅栏、树篱、树木、水塘。
- 放置农夫，移动/添加/删除最多三头牛，并可切换当前牛。
- 用「出口格」工具添加/移除出口；出口不能与农夫、牛、墙或固定障碍重叠。
- 用「固定障碍」工具添加/移除固定干草垛。
- 调整回合上限、预测步数、视野距离、出口视野。
- 切换牛朝向、出口/逃跑平局方向、牛挡视线、牛互相阻挡。
  所有牛行为统一，不再提供行为开关。
- **导出验证：** 导出前调用与游戏/测试相同的 `game.solver.solve_level`。
  状态空间穷尽且无解时拒绝导出并给出中文原因；搜索达到上限时弹窗让玩家选择
  「取消」或「仍然导出（未验证）」。已验证文件记录
  `verification: {status, shortest_turns}`；未验证文件在导入时提示。
- 导入读取文件中的第一张关卡。关卡名固定为「我的牧场」，暂不支持文字输入。

## 关卡数据格式

```json
{
  "version": 5,
  "game": "The Tamworth Chase",
  "levels": [
    {
      "id": "level_01",
      "name": "朝哪走",
      "grid": ["#######", "#.....#", "..."],
      "fj_start_direction": "north",
      "cow_facings": ["east"],
      "exit_cells": [[1, 1]],
      "max_turns": 14,
      "prediction_steps": 5,
      "exit_sight_range": -1,
      "sight_range": -1,
      "exit_tiebreak": "right",
      "flee_tiebreak": "right",
      "cows_block_sight": false,
      "cows_block_each_other": false,
      "walls": [],
      "obstacles": [],
      "chapter": "基础驾驶",
      "learning_objective": "转向与前进：每回合必须转向或前进",
      "hint_text": ["W/↑ 朝上，S/↓ 朝下…", "空格前进…"],
      "hint": "先转向，再前进。",
      "description": "渐进式主线第一课。"
    }
  ]
}
```

| 字段 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `id` | string | 必填 | 唯一关卡 id |
| `name` | string | id | 中文显示名 |
| `grid` | string[] | 必填 | 地形行；`F` 农夫，`C` 牛 |
| `fj_start_direction` | string | `north` | 农夫初始朝向（也接受 up/right/down/left） |
| `cow_facings` | string[] | `east` | 每头牛的初始朝向 |
| `exit_cells` | `[row,col][]` | 必填 | 出口；不能与墙、固定障碍或农夫初始位置重叠 |
| `max_turns` | int | 30 | 回合上限 |
| `prediction_steps` | int | 5 | 预测步数；0 关闭 |
| `exit_sight_range` | int | -1 | 出口视野距离；-1 无限 |
| `sight_range` | int | -1 | 农夫视野距离；-1 无限 |
| `exit_tiebreak` / `flee_tiebreak` | `right` / `left` | `right` | 平局方向 |
| `cows_block_sight` | bool | false | 牛是否挡农夫视线 |
| `cows_block_each_other` | bool | false | 牛是否互相阻挡移动 |
| `walls` | `[row,col][]` | `[]` | 可选的额外栅栏坐标（会折进网格） |
| `obstacles` | `[row,col][]` | `[]` | 可选的固定干草垛 |
| `chapter` | string | group | 关卡选择页的章节标签 |
| `learning_objective` | string | `""` | 中文教学目标；普通关为空 |
| `hint_text` | string 或 string[] | `[]` | 渐进式中文提示 |
| `s/a/b_threshold` | int | 自动推导 | 按回合数的评价阈值 |
| `hint` / `description` | string | `""` | 中文界面文本 |
| `verification` | object | 无 | 编辑器导出的求解器验证信息 |

网格字符：`.` 草地、`,` 花、`#` 栅栏、`T` 树、`~` 水塘、`H` 树篱、
`F` 农夫、`C` 牛。旧地图里的 `D/G/S` 仍按普通牛读取；牛不能出生在出口上；
农夫也不允许出生在出口上。

**向后兼容：** 旧的 `step_limit`、`obstacle_limit`、`initial_obstacles`、
`win_condition`、`pen_cells`、`cow_behavior`、牛性格和道具字段会被忽略；
`step_limit` 作为 `max_turns` 的回退。旧 `tips`/`practice` 教程字段会被忽略。
旧关卡没有出口时，会选一个确定性的远端可走格作为默认出口并标记 legacy。

## 存档

- 默认：`~/.the_tamworth_chase/save.json`
- 覆盖：环境变量 `TAMWORTH_CHASE_DATA`
- 改名前的旧环境变量仍然兼容。
- 改名后的首次启动会把旧存档复制到新位置，旧文件不删除，并用中文弹窗提示；
  旧存档损坏时提示并使用全新存档，不会崩溃。
- 存档版本 **6** 移除独立 `tutorial` 段。已知旧教程完成状态按
  `basics_01`→`level_01`、…、`advanced_03`→`level_10` 映射到主线通关；
  无法映射的教程状态（如编辑器教程、跳过状态）忽略。
- 存档分区：`settings`、`main`、`achievements`、`challenges`、`daily`、`custom`。
  写入采用原子替换；`hints` 默认开启。

## 字体与许可

- `assets/fonts/CEFFontsCJK-Regular.ttf`：CEF Fonts CJK，SIL Open Font License 1.1；
  全文在 `assets/fonts/OFL.txt`。
- 运行时从本地加载，不联网下载。
- CEF 的数字 `1` 形似斜杠，所以连续数字用系统圆体（SF Rounded、Avenir Next、
  Helvetica Neue、DejaVu Sans、Arial）渲染；中文和拉丁字母保留手写体。
  字体缺失时回退到系统 CJK 字体。

## 美术与音效

- 地形、栅栏、水塘、牛、农夫、出口门、干草垛、警觉气泡全部程序化绘制；
  地块先高分辨率绘制再平滑缩小。
- 没有位图精灵表，也没有用 emoji 充当游戏对象。
- 音效在启动时由 `game/audio.py` 合成；仓库不包含音频文件。设置页可调音量/静音。

## 设计说明与假设

- **全部抓住才胜，任一牛到出口即负。**
- **回合上限**：达到 `max_turns` 仍未胜利即失败；同一回合的胜利判定先执行，
  最后一回合仍可获胜。
- **同方向转向**：无效且不消耗回合。
- **逃跑只是临时避让**：前进或左右转都无法增大距离时，立即回落到出口逻辑；
  四邻全堵则原地不动。
- **出口只对牛开放**：农夫的可行走判定排除出口；加载时拒绝农夫与出口重叠。
  牛可以进入出口并立即失败，因此不存在“站在出口上堵牛”的玩法。
- **出口直线视野**：严格同行/同列；对角出口不可见，牛走巡逻。
- **被抓住的牛离开棋盘**：快照保留位置用于撤销，移动/视线/出口/渲染跳过。
- **教学目标只用于提示**：不影响胜利、评价和解锁。
- **固定地形**：网格 + 可选 `walls` / `obstacles`。
- **预测**只模拟牛，农夫固定；未实现“农夫候选动作”进阶预测。
- **求解器**使用确定性节点上限；穷尽状态空间为不可解，达到上限为未验证。

## 已知限制

- 图形界面通过无窗口截图与注入事件验证，未在物理显示器上人工试玩。
- 音效在 dummy 设备下运行，未做听感验收。
- 编辑器关卡名固定、画布固定 10×10。
- 每日生成器所有候选都失败时回退到主线第一关。
- 每次尝试最多保留 256 个撤销快照。
- 挑战关难度更紧；其中两关的最短解正好等于回合上限。
- 四个相邻格全堵的牛会原地不动；这是安全兜底，不是有趣的谜题状态，
  现有关卡避免该设计。
- 解析器本身不限制 10×10，但编辑器画布限制为 10×10。
