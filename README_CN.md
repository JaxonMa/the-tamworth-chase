# The Tamworth Chase

*一款用纯 Python 制作的手绘田园风网格追逐解谜游戏。*

农夫 John 和他的牛走路方式一模一样：前方能走就前进一格，否则顺时针转 90° 原地不动。
两位主角永远同步移动。你要在追逐开始前放下干草垛、摆好道具，
让两条路线互相咬合，在步数用完之前让农夫抓到牛——同时别让时间绕成一个圈。

游戏完全离线：没有账号、没有服务器、没有遥测，运行时不发起任何网络请求。

## 改名说明

本项目原名为 **The Tamworth Two**，从本版本起统一更名为 **The Tamworth Chase**，

## 功能特性

- 10 张手工设计的 10×10 主线牧场，难度循序上升。
- 严格同步的双主角追逐模拟，带完整的时间闭环检测。
- 有限次数的干草垛与道具放置、撤销，以及前三步轨迹预测。
- 播放控制：开始、暂停、单步、0.5× / 1× / 2× 速度、重开。
- 基于步数的 S/A/B/C 评价，最好成绩保存在本地。
- 独立的新手教程体系：三个章节、独立入口、独立进度与独立状态机。
- 四种牛性格、六种可放置道具、五个挑战关卡、本地每日种子牧场，
  以及支持 JSON 导出 / 导入的关卡编辑器。
- 六个本地成就。
- 界面、关卡名、提示与弹窗全部为简体中文。
- 全部美术由代码程序化绘制；项目里唯一的二进制资源是内置字体。

## 环境要求

- Python 3.10 或更高版本（开发与验证环境为 CPython 3.14）。
- 可用的桌面窗口环境（macOS、Windows 或 Linux）。
- `pygame-ce` 负责窗口、绘制与音频；`pytest` 仅用于测试。

## 虚拟环境与安装

项目使用仓库根目录下的 `.venv/` 虚拟环境。

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Windows（PowerShell）：

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如果不激活环境，也可以直接使用显式解释器路径：

```bash
.venv/bin/python main.py
.venv/bin/python -m pytest
```

依赖在 `requirements.txt` 中限定版本范围：

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| pygame-ce | >=2.5,<2.6 | 窗口、渲染、输入与音频混音 |
| pytest | >=8,<9 | 仅用于单元测试 |

## 运行游戏

```bash
.venv/bin/python main.py
```

启动后无需任何命令行参数。所有进度保存在本地 JSON 文件中（见[存档位置](#存档位置)）。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 鼠标左键 | 放下当前选中的干草垛 / 道具，或收回光标下的东西 |
| 鼠标右键 | 收回光标下的东西 |
| `空格` | 开始追逐，或暂停 / 继续 |
| `S` 或 `→` | 单步前进一回合 |
| `R` | 重开本关 |
| `1` / `2` / `3` | 播放速度切换为 0.5× / 1× / 2× |
| `P` | 开 / 关前三步预测 |
| `Esc` | 返回 |

所有操作也都能在右侧面板的按钮上完成。关卡编辑器里左键绘制、右键擦除。

## 游戏规则

1. 棋盘是 10×10 的牧场，四周被栅栏包围。
2. 农夫 John 与每一头牛都占据一个格子，并朝向东南西北之一。
3. 每一回合所有角色**同步**推进：先根据当前状态计算农夫和所有牛的下一状态，
   再统一提交，绝不允许先动一方。
4. 若正前方格子可通行，则前进一格并保持朝向；否则原地顺时针旋转 90°，本回合不移动。
   （倔牛改为逆时针旋转。）
5. 栅栏、树篱、树木、水塘、边界、干草垛和临时木墙都会阻挡移动。
   角色之间互不阻挡——他们可以迎面交换格子而不会相遇。
6. 若一回合结束后农夫与某头牛处在同一格，即抓住牛，立即获胜。
7. 若完整状态重复出现——农夫位置与朝向、每头牛的位置与朝向、障碍布局、
   道具状态与陷住标记——判定进入时间闭环，本局失败。
8. 若步数预算耗尽仍未抓住牛，本局失败。

模拟逻辑位于 `game/core.py`，完全不依赖 pygame，因此上述每条规则都有单元测试覆盖。

## 进度、评价与解锁

- 主线关卡按顺序解锁：通关当前关才会开启下一关。
- 评价只看使用步数：
  - **S** —— 不超过该关的 S 阈值
  - **A** —— 不超过 A 阈值
  - **B** —— 不超过 B 阈值
  - **C** —— 完成关卡但超过 B 阈值
- 每关保存最好步数与最好评价；评价只升不降。
- 教程进度保存在存档的**独立分区**，绝不影响主线解锁；主线进度也不会把教程课标记为完成。

## 新手教程章节

新手教程是独立的章节体系：主菜单有独立入口，拥有自己的课程列表与状态机
（`not_started` / `in_progress` / `completed` / `skipped`）。

| 章节 | 文件 | 内容 |
| --- | --- | --- |
| 基础教程 | `tutorials/basics.json` | 移动、转向、放置与撤销干草垛、同步移动、前三步预测、抓牛、闭环节奏 |
| 进阶教程 | `tutorials/advanced.json` | 第二头牛、牛的性格、苹果、喇叭、泥地与路标 |
| 编辑器教程 | `tutorials/editor.json` | 绘制地形、摆放角色、导出与导入关卡 |

- 每节课只引入一个新机制，提示会按玩家的操作顺序出现（放置、开始、获胜、失败）。
- 每节课都可以重玩；已完成的课程保持完成状态。
- 单节课与整个章节都可以跳过；章节页与设置页都提供重置入口。
- 教程课程只记录完成状态，不参与 S/A/B/C 评价。
- 首次启动时主菜单会提示「初次游玩？试试新手教程。」，但绝不强制跳转。

教程状态、解锁与存档隔离实现在 `game/tutorial.py`，并由 `tests/test_tutorial.py` 覆盖。

## 牛的性格

| 性格 | 行为 |
| --- | --- |
| 普通牛 | 被挡住时顺时针转身。 |
| 倔牛 | 被挡住时逆时针转身。 |
| 贪吃牛 | 被挡住时若旁边有苹果，会先走过去吃。 |
| 胆小牛 | 听到喇叭声会掉头，并且在可能时后退一格。 |

关卡网格用 `C`、`D`、`G`、`S` 放置不同性格的牛；抓住任意一头牛即获胜。

## 道具

道具在追逐开始前放置，数量由关卡的道具数量限制。

| 道具 | 效果 |
| --- | --- |
| 苹果 | 任何角色踩到都会吃掉；贪吃牛会被相邻的苹果吸引。 |
| 泥地 | 踩进去的角色下一回合陷住，只能原地转身。 |
| 临时木墙 | 阻挡 8 个回合，然后自行散开。 |
| 路标 | 角色踩上去后立刻转向箭头方向。 |
| 喇叭 | 所有牛掉头；胆小牛还会后退一步。 |
| 成对传送门 | 踩进一扇门会从配对的门出来（必须成对放置）。 |

## 挑战模式与每日牧场

- **挑战模式**提供五个精选小谜题：双牛同场、苹果引路、喇叭惊牛、泥地机关和一步抓牛。
  最好步数保存在本地，不占用主线进度。
- **每日挑战**由本地日期推导出一片牧场。生成时会用有限的搜索验证可解性，
  保证当天的牧场一定能通关；成绩按日期保存在存档里，任何数据都不会上传。

## 关卡编辑器

关卡编辑器可以：

- 绘制草地、栅栏、树篱、树木与水塘；
- 摆放和移动农夫与牛，切换农夫朝向与牛的性格；
- 设置障碍上限与步数上限；
- 用真实模拟立即试玩；
- 把关卡导出为 JSON 到 `custom_levels/`，并重新导入。

编辑器教程章节使用同一个编辑器，并带有分步任务（画三格栅栏、移动两位主角、导出再导入）。

## 字体与许可

界面使用 **CEF Fonts CJK（快去写作业CJK）**。这是一款完全用鼠标绘制字形的仿手写字体，
为界面带来绘本般的亲近感。

- 字体：CEF Fonts CJK，Regular
- 作者：Partyb0ssishere
- 来源仓库：<https://github.com/Partyb0ssishere/cef-fonts-cjk>
- 许可：SIL Open Font License, Version 1.1
- 本地文件：`assets/fonts/CEFFontsCJK-Regular.ttf`
- 许可全文：`assets/fonts/OFL.txt`

字体在开发阶段一次性下载并随仓库分发，游戏运行时**不会**联网加载。
OFL 允许免费使用、嵌入与再分发，前提是保留许可文本，且不得单独售卖字体文件本身。

`game/theme.py` 处理了两个实际问题：

1. **回退链**：内置字体缺失时，依次回退到系统圆体 / 黑体，再到系统默认中文字体，
   确保任何机器上中文都可读。
2. **数字可读性**：CEF Fonts CJK 的 `1` 是一笔斜杠，容易与 `/` 混淆。
   因此数字使用圆体系统字体渲染（SF Rounded → Avenir Next → Helvetica Neue →
   DejaVu Sans → Arial → 内置字体），中文与拉丁字母保留手写体风格。
   正文最小字号为 18 px。

## 美术、音效与离线资源

- **美术**：所有画面元素都由 `game/art.py` 与 `game/render.py` 在运行时程序化绘制：
  带柔和纹理的草地、与相邻格自动连接的木栅栏、树篱、树林、水塘、农夫、
  四种朝向与不同性格的牛、干草垛、苹果、泥地、木墙、路标、喇叭与传送门。
  游戏不包含任何位图精灵表。
- **音效**：所有音效都在启动时由 `game/audio.py` 用简单波形合成，没有音频文件需要下载。
  设置页可以关闭音效。
- **离线**：游戏不发起任何网络请求。仓库中唯一的二进制资源是内置字体。

## 存档位置

进度以 JSON 形式保存在仓库之外：

- 默认：`~/.the_tamworth_chase/save.json`
- 覆盖：启动前设置环境变量 `TAMWORTH_CHASE_DATA` 指向自定义目录；
  改名前的旧环境变量仍然兼容。

存档把以下分区严格分开：`settings`、`main`（主线）、`tutorial`（教程）、
`achievements`、`challenges`、`daily`。写入采用原子替换；存档损坏时会回退为全新存档而不是崩溃。

## 设计说明与假设

- **同步是构造出来的**：每回合先计算所有角色的下一状态，之后再统一提交；
  这是角色交换格子时规则仍然正确的唯一做法。
- **时间闭环的状态键**：包含农夫格与朝向、每头牛的格与朝向、障碍布局、
  道具状态与陷住标记。一旦新回合产生已经出现过的键，本局以时间闭环结束。
- **步数预算**：上限为 n 步的关卡恰好允许 n 次移动。
- **放置规则**：干草垛与道具不能放在栅栏、树、水塘、树篱、牧场之外、
  角色身上或彼此身上，追逐开始后也不能再放。传送门必须成对；未配对的传送门
  会在开始时被移除。
- **评价**只由步数推导，结果确定、可测试，不涉及隐藏计时。
- **每日牧场**：日期作为种子驱动确定性生成；候选关卡会用有限搜索
  （不放、放一捆、放两捆）验证可解性，保证当天一定能通关；
  如果所有候选都失败，则回退到一张主线牧场。
- 渲染以 60 FPS 运行，可在设置中开启低配模式（关闭粒子与复杂动效）。
